## [0.1.0] - 2026-07-31

### Added

- Resumable Arch WSL installer with explicit restart checkpoints and per-phase state.
- Fresh-root user bootstrap with systemd, default-user, sudo, and interop configuration.
- Bloody Writer Zsh/Agnoster, tmux, Neovim, and Windows Terminal theme snapshot.
- Responsive Neovim shortcut guide and broader operations cheat sheet.
- Locked Neovim plugin graph and verified English/Spanish spell files.
- Pinned Oh My Zsh and Codex CLI releases, with the official OpenAI developer-docs MCP.
- Safe GitHub authentication, dedicated SSH-key generation, and keychain reuse.
- `tma` interactive tmux session picker supporting simultaneous local and phone clients.
- Optional Tailscale SSH setup for Android Termux.
- Automatic pre-change backups, update/status/doctor/backup commands, tests, CI, and security
  documentation.
